## Implementation and verification order

1. Protect learner work first. Finish draft preservation, mute persistence, quiz and review focus, and language-aware link recovery.
2. Apply the shared foundation. Align the workspace headers and content edges, centralize the palettes, and standardize controls and feedback. Use the existing icons and native dialogs. Keep motion brief and respect reduced-motion preferences.
3. Check the running Client in both languages. Compare desktop, tablet, and phone layouts with the Phase 14 baseline. Exercise keyboard navigation, signed-out links, language switching, slow and failed requests, draft recovery, quiz completion, and the short-landscape room.
4. Document the results in Phase 15. Record what was resolved, what moved to a later page pass, and which scenarios were verified with fixtures or live services.

Phase 14 reproduced the main issues in the browser with fixture accounts. The partial Phase 15 edits still need build and browser validation.
